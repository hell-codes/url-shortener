How a link gets stored

The insert path from a long URL to a slot in the hash table.

01

Validate & generate

The URL is checked, then a short alphanumeric code is generated.

02

Hash the code

A hash function maps the code to a slot index in the table's array.

03

Linear probing

If that slot is taken, the table checks the next slot until one is free.

04

Persist & respond

The mapping is saved to JSON and the short URL returns instantly.
